# Smart Building Digital Twin

A data-driven Python project that analyzes real building data to understand energy consumption, identify unusual energy-use patterns, and simulate different occupancy scenarios.

## Project Objectives

* Analyze building energy consumption
* Detect unusual energy-use patterns
* Understand the relationship between occupancy and energy usage
* Predict energy consumption using machine learning
* Simulate different occupancy scenarios

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Random Forest

## Machine Learning

The project uses a Random Forest regression model to predict energy consumption.

**Model Performance:**

* R² Score: 0.4716
* MAE: 0.3574

## Key Insights

The project helps identify unusual energy consumption and understand how changes in building occupancy can affect energy usage.

## Project Type

Data Analytics | Machine Learning | Smart Building | Energy Analysis
